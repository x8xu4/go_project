# LogosGo - 落即知 (老狗)

> 「落子即知其理」—— 不只是給出勝率，更是解釋圍棋的邏輯。

LogosGo 是一個基於 KataGo 引擎開發的圍棋分析軟體，旨在解決現有 AI 缺乏語義化解釋的問題。
我們不只告訴你哪裡好，更致力於分析為何而戰，幫助棋手突破學習瓶頸。

專案目標：圍棋高段者訓練助手 (Go-Elite Trainer)

核心概念：將 AI 的冷冰冰數字「邏輯化」。

具體待辦功能：

[邏輯對比]：支援「實戰手」與「推薦手」的 10 手預判路徑同時顯示。

[脫先判定]：計算全盤熱點，若實戰手與 AI 推薦手距離 > 6，則判定為大局觀選擇，並分析兩處價值比。

[術語標籤]：利用座標判斷演算法，自動判別 AI 的下法是屬於「侵分」、「定型」還是「攻擊」。

[死活警示]：掃描全盤氣數 <= 3 的棋塊，若 AI 勝率變動與此相關，則高亮該區域。
