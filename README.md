# LogosGo V1.0.0

> 「落子即知其理」—— 不只呈現勝率，也協助理解局勢變化與棋步選擇。

LogosGo 是以 KataGo 為分析基礎的圍棋復盤助手。它可以匯入 SGF、分析整盤棋、挑選值得回顧的關鍵手，並以客觀數據與保守、可追溯的文字講解協助棋手復盤。

## 系統需求

- Apple Silicon Mac（M 系列晶片）
- macOS 26.0 或更新版本
- 約 350 MiB 儲存空間，分析時需額外可用記憶體與暫存空間

目前提供的是私有、ad-hoc 簽署版本，尚未使用 Developer ID 簽署或經 Apple notarization。第一次開啟時 macOS 可能顯示安全性警告；請確認檔案來源可信，再依系統提示使用「打開」或至「隱私權與安全性」允許開啟。

## 開始使用

1. 解壓縮 `LogosGo-v1.0.0-macOS-arm64.zip`。
2. 雙擊 `LogosGo.app`。不需要先啟動 Terminal、Python、Flask 或 KataGo。
3. 按「匯入 SGF」並選擇棋譜。LogosGo 只讀取棋譜，不會修改原始 SGF。
4. 匯入後會自動開始整盤分析；講解欄會顯示已完成手數、百分比與動態預估剩餘時間，也可用「取消整盤分析」停止背景工作。
5. 使用前後手控制切換局面，查看 KataGo 客觀數據與 LogosGo 講解。

## 主要功能

- **本局復盤**：整盤分析完成後，集中列出重要轉折，並可依時間順序逐項查看。
- **推薦變化圖**：有可靠 PV 時，點擊講解欄的連結即可進入既有試下模式，棋盤以 1～N 顯示推薦手順。
- **試下模式**：可自行在目前局面繼續落子探索；結束試下後會恢復正式棋譜，不會把試下內容寫回 SGF。
- **形勢判斷**：在任何目前局面按下「形勢判斷」，顯示 ownership、估計分差、勝率、領地與提子資訊；關閉浮動視窗即清除 overlay。
- **提問／為什麼？**：普通手可按需取得更完整講解；同一棋譜同一手的成功結果會在目前工作階段合理重用。

## 如何理解講解

KataGo 的勝率、目數、候選著與 PV 是客觀分析資料；LogosGo 的文字則是根據目前可觀察 evidence 產生的解釋。當證據不足時，系統會採取保守說法或明確表示無法可靠判斷，不應把講解視為對所有局部棋理、死活或後續變化的絕對證明。

## 結束程式

關閉 LogosGo 視窗即可退出。App 會一併停止內建 backend 與 KataGo；不需要手動結束背景服務。
